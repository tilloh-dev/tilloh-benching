Write a Python 3 command-line program `fizzbuzz.py`.

Requirements:
- Usage: `python3 fizzbuzz.py N` where N is a positive integer.
- Print the numbers 1 to N, one per line, replacing multiples of 3 with "Fizz", multiples of 5 with "Buzz" and multiples of both with "FizzBuzz".
- Print nothing else to stdout.
- If N is missing or not a positive integer, print a short usage message to stderr and exit with status 2.
- Standard library only.
